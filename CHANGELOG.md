# Changelog

## 2026-09-01 — Real-time predictions & standings fixes

### Fixed
- `cron-daily-predictions` was generating predictions off a hardcoded, recurring fictional fixture list instead of real matches. Rewritten to pull real upcoming fixtures from API-Football (RapidAPI or direct API-Sports) for the top 5 European leagues + Champions League, dedupe against existing fixtures, and feed each through the AI prediction pipeline.
- `fetch-standings` now tries a direct `API_SPORTS_KEY` before the RapidAPI proxy, and tags its response `source: 'live-api'` vs `'verified-feed'` so the client can tell real data from the static fallback.
- `src/hooks/useFootballData.ts` now only marks standings as live when the edge function reports `source === 'live-api'`, instead of assuming any non-empty response was live.
- `generate-prediction` and `ai-chat` were calling `gemini-1.5-flash`, a model Google has fully retired (returns 404). Every "AI" prediction had been silently falling back to a generic default (Home Win, 65% confidence, fixed odds). Switched both to `gemini-flash-latest` and added real error logging instead of a silent catch.
- `generate-prediction` was writing every prediction — including one-off "what-if" lookups from the Match Predictor tool and Other Sports demo page — into the same shared `predictions` table that powers the homepage. It now only persists when a real `fixture_id` is supplied by the fixtures pipeline.
- `supabase/config.toml` `project_id` was pointing at an old, empty Lovable project instead of the live project — CLI deploys from this repo risked going to the wrong place.

### Cleaned up (database, not code)
- Purged fabricated placeholder rows from the `predictions` table: recurring `ai-*` fake fixtures generated by the old cron job, plus older seeded fictional data (`wc26-*` fake World Cup matches, `pp-today-*` fake recurring fixtures) that had been sitting in the table since June/July 2026.
- Unscheduled two harmful/broken pg_cron jobs: `refresh-prediction-dates` (was rewriting any past-dated prediction to a random future date instead of removing it, and fabricating fake probability/score metadata) and `sync-sportmonks` (orphaned function, hardcoded to 2 fixture IDs, needed a secret that was never set).

### Known issues / still open
- All football-data API keys currently configured for this project are unusable: one RapidAPI key isn't subscribed to the API-Football product it's being used against, and two others (a "cheaper" free-football-data API and the Boggio Analytics football-prediction-api) have exceeded their monthly quota. Real-time fixtures/standings/predictions won't flow until one of these is fixed or a new key is added.
- `fetch-real-predictions` (a working real predictions+odds pipeline against football-prediction-api) exists live on Supabase but was never committed to this repo and isn't wired into any cron schedule.
- A number of other Supabase Edge Functions run in production but are not present in this repository: `fetch-real-predictions`, `fetch-highlights`, `search-players`, `fetch-odds`, `daraja-stk`, `generate-daily-blog-posts`, `send-daily-digest`, `paystack-webhook`, `paystack-initialize`, `paystack-verify`, `telegram-broadcast`, `debug-sportmonks-check`, `sync-sportmonks`. Repo/production reconciliation is still outstanding.
